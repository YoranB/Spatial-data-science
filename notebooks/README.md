# Notebooks

## Core Analysis

The notebooks in [`01_core/`](01_core/) form the recommended reading order for this project.

- [`01_build-analysis-dataset.ipynb`](01_core/01_build-analysis-dataset.ipynb): assembles the neighborhood-level analysis dataset.
- [`02_crime-choropleth.ipynb`](01_core/02_crime-choropleth.ipynb): visualizes neighborhood crime rates on the Amsterdam map.
- [`03_spatial-autocorrelation.ipynb`](01_core/03_spatial-autocorrelation.ipynb): measures global and local spatial clustering.
- [`04_ridge-model.ipynb`](01_core/04_ridge-model.ipynb): estimates the ridge regression model and interprets feature effects.

## Archive

[`99_archive/`](99_archive/) contains exploratory and preparatory notebooks retained for provenance. Some of these notebooks reference source files that are no longer included in the repository, so they are not part of the supported execution path.
