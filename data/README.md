# Data Layout

- [`raw/`](raw/): original inputs used during the project.
- [`intermediate/`](intermediate/): merged and engineered tables created during cleaning and feature construction.
- [`final/`](final/): the final model-ready dataset used by the curated analysis notebooks.
- [`archive/`](archive/): historical artifacts preserved for provenance.

For dataset-level details, provenance notes, and notebook dependencies, see [`docs/data-catalog.md`](../docs/data-catalog.md).
